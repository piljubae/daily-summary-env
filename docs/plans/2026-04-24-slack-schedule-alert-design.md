# Slack 일정 알림 섹션 분리 설계

**날짜**: 2026-04-24  
**목표**: 슬랙 멘션에서 날짜가 박힌 임박 일정을 추출해 작업 플랜과 분리된 별도 섹션으로 노출

---

## 배경

현재 Gemini가 생성하는 "오늘의 플랜"에 작업(티켓/PR)과 일정(SDK 수령, 입사, 배포 등)이 섞이거나 일정이 누락됨.  
슬랙 `.md` 파일에 `Next Action` + 날짜 정보가 있음에도 Gemini 프롬프트에 추출 지시가 없어서 플랜에 반영되지 않음.

---

## 설계

### Gemini 프롬프트 변경 (`formatters/markdown.py`)

기존 파트 구조에 **파트 0** 추가:

```
파트 0: 오늘/이번주 챙길 일정
파트 1: 어제의 핵심 활동 (기존)
파트 2: 오늘의 작업 플랜 (기존)
```

**파트 0 추출 규칙:**
- Slack 컨텍스트의 Next Action, 날짜 언급 항목을 스캔
- 오늘 날짜 → `[오늘]` 태그
- 내일 날짜 → `[내일]` 태그
- 이번 주 내 → `[N/N 요일]` 태그
- 임박 순(오늘 → 내일 → 이번주) 정렬
- 슬랙 관련 항목이 없으면 파트 0 생략 (안내 문구 없이)

**출력 형식:**
```
**⚠️ 오늘/이번주 챙길 일정**

- [오늘 4/24] CS 챗봇 SDK 수령 → 앱 개발 일정 확정 필요
- [4/27 월] 박지은님 입사 → 온보딩 준비
- [4/28 화] 노출표준화 배포 팔로업
```

### Slack 메시지 구조 변경 (`formatters/slack.py`, `formatters/markdown.py`)

**변경 전**: AI 요약 덩어리 하나 (일정 + 작업 혼재)

**변경 후**:
```
⚠️ 오늘/이번주 챙길 일정     ← 파트 0 (슬랙 임박 일정)
- [오늘] ...
- [4/27 월] ...

📌 오늘의 작업 플랜           ← 파트 2 (기존 작업 플랜)
1. KMA-xxxx ...
```

- 파트 1(어제 핵심 활동)은 Slack 메시지에서 제외 (MD 파일에만 저장)
- 파트 0이 없으면(슬랙 일정 없음) 작업 플랜만 전송

---

## 파일 변경 범위

| 파일 | 변경 내용 |
|---|---|
| `formatters/markdown.py` | 프롬프트에 파트 0 추가, 파트 0 파싱 후 반환 |
| `formatters/slack.py` | Slack 메시지 포맷에 일정 섹션 최상단 배치 |
| `daily_summary.py` | `summarize_with_gemini` 반환값에서 파트 0 추출해 Slack 포맷터에 전달 |
